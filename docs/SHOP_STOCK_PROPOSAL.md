# Shop stock proposal

Draft balancing proposal, not an export of the current game economy. Prices use **credits as a provisional currency label**. Nothing here has been added to the game.

Start with 10–20 credits for ordinary supplies, 50–150 for basic gear/furniture, and 200–650 for upgrades and rare decor. Scale all prices together once typical daily earnings and mission rewards are known. Prices are not tuned against unseen game values.

Rules: ordinary shops restock each morning; Ooma rotates 3–4 clearly displayed items each scheduled visit; known recipes disappear from stock; proposed resale value is 30% of purchase price. Drinks provide at most one active timed buff, with a new drink replacing the prior one. All effects and unlocks below are proposals. Avoid consumable dyes if the appearance customizer already offers free recoloring. Keep medpacks at Maren’s Medbay and meals at the mess hall. Ooma never exclusively gates a required quest item.
